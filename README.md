# Indian Job Market Intelligence & Skill Gap Analysis

## Project Overview
This project explores Indian job postings to identify popular job titles, hiring locations, in-demand skills, and salary patterns using Python.

## Objectives
- Analyze popular job titles in the Indian job market.
- Identify locations with the highest number of job postings.
- Explore frequently mentioned skills in data-related roles.
- Compare salary ranges for selected job titles.
- Present findings through charts and visualizations.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Findings
- Application Developer was the most frequent job title in the dataset, with 2,033 postings.
- Bengaluru had 16,783 overall job postings.
- Python was the most-mentioned skill in the selected data-related postings, with 1,509 mentions.
- SQL was the second most-mentioned skill, with 1,220 mentions.
- Bengaluru had 1,578 postings in the data-related subset.

## Project Workflow
1. Loaded the job market dataset.
2. Checked duplicate records and missing values.
3. Explored job titles and locations.
4. Analyzed skills in data-related job postings.
5. Examined salary ranges.
6. Created charts and a combined dashboard.
7. Summarized findings and recommendations.

## Business Recommendations

## Conclusion
This project demonstrates how Python can be used to explore job market trends and communicate findings through data visualization.

## Notes
The findings reflect the dataset analyzed and should not be interpreted as exact statistics for the entire Indian job market. Salary comparisons should be treated as preliminary until salary units are standardized.
